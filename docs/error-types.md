# 예제의 오류 유형 코드

이 표는 함께 제공한 자체 출제 예제와 향후 평가셋을 위한 **초기 분류안**이다.
기존 연구나 실제 수업에서 검증된 분류 체계라는 의미는 아니다. 분류를 바꾸면
평가셋과 문서에 버전을 기록한다. 하나의 답안에는 여러 코드가 붙을 수 있다.

| 코드 | 의미 | 확인할 사례 |
| --- | --- | --- |
| E1 | 주어진 조건 누락·오독 | 두 조건 중 한 조건만 이용 |
| E2 | 경계·초기 조건 처리 오류 | $1+C=3$에서 $C=3$이라고 결론 |
| E3 | 논증 단계 누락 | 필요한 함의나 근거 없이 결론 |
| E4 | 대수·미분·적분 계산 오류 | 부호, 계수, 연산 오류 |
| E5 | 정의역·경계·성립 조건 오류 | 분모가 0인 경우 미검토 |
| E6 | 잘못된 최종 결론·검증 실패 | 조건을 만족하지 않는 함수를 최종 제시 |
| E7 | 부당한 정리 적용·역추론 | 충분조건을 필요조건으로 오해 |

`error_types`는 답안 **전체에 붙인 의도된 오류 라벨**이며 모델에 전달하지 않는다.
유형별 지표는 그 라벨이 있는 답안의 모든 루브릭 항목으로 계산된다.
따라서 특정 항목의 실제 오류 유형을 정밀하게 찾아냈다는 뜻으로 해석하면 안 된다.
다중 라벨 답안은 여러 유형에 포함되므로 유형별 표의 수를 더해 전체 수로 삼지 않는다.

`is_alternative: true`는 올바른 대안 풀이를 따로 확인하기 위한 평가 메타데이터다.
모델에 전달하는 인정 가능한 풀이 설명은 문항의 `alternatives`에만 넣는다.
