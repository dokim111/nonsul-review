# nonsul-review v0.1.0 (pre-release)

> **게시용 초안 — 소스는 [GitHub](https://github.com/dokim111/nonsul-review)에 공개했고, [초기 공개 커밋의 CI](https://github.com/dokim111/nonsul-review/actions/runs/36523220236)는 통과했습니다. 실제 API 검증과 GitHub pre-release·PyPI 게시는 아직 이 문서에서 완료로 기록하지 않습니다.** 최종 공개 실행 증거와 CI를 확인한 뒤 아래 기록을 채우고, 게시용 초안 표시를 제거하세요.

수리논술 강사용 판정 초안·검수·평가 CLI의 첫 사전 공개 버전입니다.

## 포함 기능

- 문항 YAML과 Markdown/LaTeX 답안의 엄격한 형식·ID 연결 검증
- 같은 원래 정보와 설정을 사용하는 루브릭 방식·자유형 방식
- 항목별 판정·실제 답안 인용·이유·피드백과 단계별 API 원본 기록
- 단일/배치 실행, dev/test 선택, 기존 결과 보존
- 강사 검수 YAML, 수정 후 확정, 변경 기록
- 최초 채점 일치도·가중 Cohen κ, 오류 탐지, 대안 풀이 오판 지적과 평가 포함률
- 공개 자체 작성 예제와 명시적인 오프라인 데모 모드
- 설치 가능한 wheel/sdist와 CI·수동 게시 절차

명세에서 이후 버전으로 예정했던 배치·검수·평가 기능도 함께 구현했습니다. API 호출이 끝까지 실행된 사실과 수학적 판정 품질을 검증한 사실은 구별합니다. 실제 게시본의 Git 저장소에는 공개 예제의 API 실행 근거가 `examples/ex-001/live/`에 포함되어 있어야 합니다. 이 근거는 실제 호출과 결과 검토를 마친 뒤 추가합니다. `results/`의 데모 fixture는 사람이 작성한 예시이며 모델 성능의 근거가 아닙니다.

## 게시 전 검증 기록

다음 항목은 실제 실행 후 기록합니다. 빈 항목이나 예정 설정을 실행 완료의 근거로 사용하지 않습니다. 작업 순서는 [첫 실제 실행 안내](first-live-run.md)와 [릴리스 절차](releasing.md)를 따릅니다.

| 항목 | 실제 확인 후 기록할 내용 |
| --- | --- |
| 공개 실행 | 실행일·시간대, `ex-001`의 a01·a02 및 rubric/free 네 실행의 성공 여부 |
| 모델·설정 | 요청 모델과 실제 응답 모델, temperature, max_tokens, timeout, 프롬프트 버전·해시 |
| 추론 설정 | 도구가 effort를 지정했는지 여부와 적용한 모델 기본값; 설정하지 않은 값을 명시적으로 전송했다고 쓰지 않음 |
| 공개 증거 | `examples/ex-001/live/evidence.json`, 결과 4개, raw 4개와 검토 여부 |
| dev 검토 | 공개 문항·답안 수, 작성자가 의도한 판정과의 비교, 확인된 불일치와 조치 |
| 개인 자료 | 공개 가능한 집계만 기재; 문항·답안·인용·raw는 공개하지 않음 |
| 배포 검증 | 최종 커밋·태그, CI 링크, build·twine·실제 실행 증거 검사 결과 |
| 남은 한계 | 해결하지 못한 판정 사례와 강사 검수가 필요한 범위 |

API 검증과 결과 검토가 모두 끝났다면, 이 절의 작성 안내와 표를 실제 확인 결과로 교체합니다. README의 현재 상태도 같은 근거에 맞춰 갱신한 뒤 배포물을 새로 빌드합니다.

## 설치·시작

첨부 wheel을 설치하거나 소스를 받아 `python -m pip install .`로 설치합니다. Python 3.10 이상이 필요합니다. 소스의 README에는 API 키 없이 실행하는 데모와 실제 API 설정, 강사 검수·확정·평가 예제가 있습니다.

이 GitHub pre-release는 PyPI 업로드를 자동으로 수행하지 않습니다. `pip install nonsul-review`는 PyPI 게시를 따로 확인한 뒤 사용합니다.

## 알려진 범위

모델 출력은 강사 검수 전 초안입니다. 판정 불가 항목은 `null`과 검수 필요 표시로 남고, 강사가 판정한 뒤 확정합니다. 현재 버전은 이미지·손글씨 인식이나 학생용 앱을 제공하지 않습니다. 공개 자체 작성 예제만으로 실제 학습자 집단에서 두 방식의 우열을 결론 내릴 수 없습니다.

GitHub에서 pre-release로 표시하지만 패키지 버전은 명세에 따른 `0.1.0`입니다. PyPI 사전 버전 표기와는 별도입니다.
