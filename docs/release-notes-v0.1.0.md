# nonsul-review v0.1.0 (pre-release)

> **게시용 초안 — 현재 준비본은 실제 API·GitHub CI·외부 게시를 완료하지 않았습니다.** 실제 공개 게이트를 통과한 뒤 검증 기록에 맞게 이 상태와 노트를 갱신하세요.

수리논술 강사용 판정 초안·검수·평가 CLI의 첫 사전 공개 버전입니다.

## 포함 기능

- 문항 YAML과 Markdown/LaTeX 답안의 엄격한 형식·ID 연결 검증
- 같은 원래 정보와 설정을 사용하는 루브릭 방식·자유형 방식
- 항목별 판정·실제 답안 인용·이유·피드백과 단계별 API 원본 기록
- 단일/배치 실행, dev/test 선택, 기존 결과 보존
- 강사 검수 YAML, 수정 후 확정, 변경 기록
- 최초 채점 일치도·가중 Cohen κ, 오류 탐지, 대안 풀이 오판 지적과 평가 포함률
- 공개 자체 작성 예제와 명시적인 오프라인 데모 모드
- 설치 가능한 wheel/sdist와 CI·수동 게시 절차

명세에서 이후 버전으로 예정했던 배치·검수·평가 기능도 함께 구현했습니다. API 호출이 끝까지 실행된 사실과 수학적 판정 품질을 검증한 사실은 구별합니다. 실제 게시본에는 공개 예제의 API 실행 근거가 `examples/ex-001/live/`에 포함되어 있어야 하며, 현재 준비본에는 이 근거가 없습니다. `results/`의 데모 fixture는 사람이 작성한 예시이며 모델 성능의 근거가 아닙니다.

## 설치·시작

첨부 wheel을 설치하거나 소스를 받아 `python -m pip install .`로 설치합니다. Python 3.10 이상이 필요합니다. 소스의 README에는 API 키 없이 실행하는 데모와 실제 API 설정, 강사 검수·확정·평가 예제가 있습니다.

이 GitHub pre-release는 PyPI 업로드를 자동으로 수행하지 않습니다. `pip install nonsul-review`는 PyPI 게시를 따로 확인한 뒤 사용합니다.

## 알려진 범위

모델 출력은 강사 검수 전 초안입니다. 판정 불가 항목은 `null`과 검수 필요 표시로 남고, 강사가 판정한 뒤 확정합니다. 현재 버전은 이미지·손글씨 인식이나 학생용 앱을 제공하지 않습니다. 공개 자체 작성 예제만으로 실제 학습자 집단에서 두 방식의 우열을 결론 내릴 수 없습니다.

GitHub에서 pre-release로 표시하지만 패키지 버전은 명세에 따른 `0.1.0`입니다. PyPI 사전 버전 표기와는 별도입니다.
