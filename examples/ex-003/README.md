# 자체 출제 예제: 뉴턴 방법으로 √3에 다가가는 수열

저자가 수리논술 강의용으로 직접 출제한 모의 문항을 공개용으로 재구성했다.
대학 기출이나 실제 학습자 답안을 복제하지 않았다. 답안은 모두 역할을 정해 직접 작성했다.

a02는 수렴 논증에서 자주 나오는 비약을 담았다. "감소하고 $\sqrt3$보다 크다"는 사실만으로는
극한이 $\sqrt3$ 이상이라는 것만 알 수 있고, 극한이 $\sqrt3$이라는 결론은 나오지 않는다.
모델이 이 비약을 부분 충족으로 잡아내는지가 이 예제의 주된 확인 지점이다.

| 답안 | 구성 | 작성 시 의도한 판정 (R1 / R2 / R3 / R4) |
| --- | --- | --- |
| a01 | 오차 상계와 샌드위치 정리로 수렴, 귀납으로 닫힌꼴 | met / met / met / met |
| a02 | 유계·감소만으로 극한을 $\sqrt3$이라 결론, 닫힌꼴 지수를 $2j$로 씀 | met / met / partial / partial |
| a03 | 산술·기하 평균으로 하한, 단조수렴 정리와 극한 방정식, $(2-\sqrt3)^{2^{j+1}}$ | met / met / met / met |

이 예제에는 데모 결과가 없다. `--demo`는 `ex-001`에만 쓸 수 있다.
실제 모델 판정은 API로 실행해 확인한다.

```bash
nonsul-review batch --problems examples/ex-003 \
  --answers examples/ex-003/answers --mode rubric --out results/ex-003-rubric
```

위 표는 작성자가 의도한 판정이며 평가자의 독립 채점이 아니다.
공개 예제는 모두 `split: dev`이므로 최종 test 평가셋으로 사용하지 않는다.
