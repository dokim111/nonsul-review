# 자체 출제 예제: 구별되는 부품으로 홈 채우기

저자가 수리논술 강의용으로 직접 출제한 모의 문항을 공개용으로 재구성했다.
대학 기출이나 실제 학습자 답안을 복제하지 않았다. 답안은 모두 역할을 정해 직접 작성했다.

점화식 도출(경우 분할의 근거), 두 단계 귀납법(기저 두 개), 모든 항에 대한 논증,
극한의 근거처럼 수리논술 채점에서 부분 점수가 갈리는 지점을 루브릭 항목으로 나누었다.

| 답안 | 구성 | 작성 시 의도한 판정 (R1 / R2 / R3 / R4) |
| --- | --- | --- |
| a01 | 가장 왼쪽 부품 분할, 두 단계 귀납, 점화식으로 홀수 증명 | met / met / met / met |
| a02 | 기저를 $n=0$ 하나만 확인, 홀수성을 몇 개 항으로만 확인 | met / partial / not_met / met |
| a03 | 가장 오른쪽 부품 분할, $a_n+a_{n-1}=2^n$ 이용, $3a_n$의 홀짝 이용 | met / met / met / met |

이 예제에는 데모 결과가 없다. `--demo`는 `ex-001`에만 쓸 수 있다.
실제 모델 판정은 API로 실행해 확인한다.

```bash
nonsul-review batch --problems examples/ex-002 \
  --answers examples/ex-002/answers --mode rubric --out results/ex-002-rubric
```

위 표는 작성자가 의도한 판정이며 평가자의 독립 채점이 아니다.
공개 예제는 모두 `split: dev`이므로 최종 test 평가셋으로 사용하지 않는다.
